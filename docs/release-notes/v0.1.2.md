Third alpha of MatRust. Many numerical routines have new implementations, with a few behaviour changes.

**This is an alpha, so expect gaps.** The [README](https://github.com/leoom-labs/matrust/blob/main/README.md) lists what works and what does not yet. Calls outside a function's stated limits are rejected with an error, not approximated.

## What's new
- **Many numerical routines have new implementations.** The help pages describe the methods used. Functions covered:
  - Iterative linear solvers: `pcg`, `gmres`, `bicg`, `bicgstab`, `bicgstabl`, `cgs`, `lsqr`, `minres`, `qmr`, `symmlq`, `tfqmr`.
  - Integrals and functions: `quadl`, `quadv`, `quad2d`, `funm`, Bessel and gamma-family special functions, `ellipke`, `ellipj`.
  - Matrices and least squares: `magic`, `pascal`, `invhilb`, `qrinsert`, `qrdelete`, `lscov`, `lsqnonneg`, `rref`, `polyeig`, `gsvd`.
  - Polynomials and filtering: `polyvalm`, `residue`, and the complex-input paths of `poly`, `polyfit`, `polyval`, `polyder`, `roots`, `conv`, `deconv` and `filtfilt`.
  - Optimisation and splines: `fzero`, `fminsearch`, `fminbnd`, `spline`, `pchip`, and the spline method of `interp2` and `interpn`.
  - Differential equations: all ODE solvers (`ode45`, `ode23`, `ode113`, `ode15s`, `ode23s`, `ode23t`, `ode23tb`, `ode15i` with `decic`), `deval`, `odextend`, `bvp4c`, `bvp5c`, `dde23`, `ddesd`.
  - Others: `rat`, `rats`, `nthroot`, the degree trig functions (`sind` to `cotd`), `var` and `std` on complex data, `hsv2rgb`, `rgb2hsv`.
- **Results can differ from 0.1.1 in the last digits.** Adaptive solvers (the ODE, BVP and DDE solvers, `fzero`, `fminsearch` and the integrals) may take different steps. Output time points, step counts and solver statistics can differ. Results, output meshes and event times can change by more than rounding, within the solver tolerances you set.
- **Behaviour changes:**
  - `ellipj(1,NaN)` returns `NaN` instead of an error.
  - `qrinsert` accepts economy-size factors; `qrdelete` accepts them for column deletion (row deletion still needs the full `Q`).
  - `qrdelete` on an empty 0x0 factorisation now errors.
  - `minres` now returns `resveccg`, the conjugate-gradient residual history, when no preconditioner is given.
  - `cscd(180)` returns `Inf`.
  - `residue` on real denominators groups repeated poles more reliably and lists them in a fixed order.
  - Complex-input `filtfilt` copes better with badly scaled coefficients and very large inputs, and reports results that overflow.
  - Three-point spline interpolation (`spline`, and the spline modes of `interp1` and `interpn`) copes better with very large values and very close points.
  - Some error messages for `hsv2rgb`, `rgb2hsv` and `rats` are reworded.
- **The README and help pages state supported inputs and limits more plainly.**

## Install
- Homebrew: `brew install leoom-labs/tap/matrust`
- Scoop: `scoop bucket add matrust https://github.com/leoom-labs/scoop-bucket`, then `scoop install matrust`
- Or download an archive below.

## Downloads
| File | System |
|---|---|
| `MatRust-0.1.2-windows-x64.zip` | Windows, 64-bit (x64) |
| `MatRust-0.1.2-linux-x64.tar.gz` | Linux, x86-64 (glibc 2.35 or newer: Ubuntu 22.04, Debian 12, Fedora 36 and later) |
| `MatRust-0.1.2-linux-x64.AppImage` | Linux, x86-64, single file: `chmod +x` it and run (same glibc minimum) |
| `MatRust-0.1.2-macos-arm64.tar.gz` | macOS on Apple silicon, unsigned |

- Each download has a `.sha256` file next to it, so you can check that the file is complete and unchanged.
- **macOS:** the programs are not signed. After unpacking, run once in Terminal: `xattr -dr com.apple.quarantine <unpacked folder>`, then start `./matrust-desktop` from that folder.
- Each archive holds three programs: `matrust-desktop` (the desktop app), `matrust` (the command line) and `matrust-pdf-worker` (a helper; keep it in the same folder).

Fourth alpha of MatRust. It adds a new app framework with 46 apps to the desktop, a PDE toolbox and a UI-component engine with App Designer, sound output, and many compatibility fixes.

**This is an alpha, so expect gaps.** The [README](https://github.com/leoom-labs/matrust/blob/main/README.md) lists what works and what does not yet. Function help lists supported inputs, limits and fallbacks.

## What's new

### Desktop apps
Open them from the Apps menu. Many also open from a launcher typed in the desktop Command Window, for example `pidTuner`, `imtool` or `nftool`. For Comparison Tool, use `visdiff(left,right)`. Filter Designer, Basic Fitting, Data Statistics, Optimize and Solve ODE have no standalone launcher and open from the Apps menu. Analysis apps can generate scripts or export results; keep the source data or figure available. App Designer saves a runnable `.m` class.
- **Curve fitting and data:** Curve Fitter, Import Tool (replaces the CSV import), Data Cleaner, Basic Fitting, Data Statistics, Comparison Tool (`visdiff(left,right)`), Profiler (`profile viewer`).
- **Signal processing:** Signal Analyzer, Filter Designer (response types, IIR and FIR methods, minimum order, spec mask, analysis views, second-order sections, export and script), Filter Visualization Tool, Window Designer, Signal Multiresolution Analyzer, Wavelet Signal Denoiser, Wavelet Time-Frequency Analyzer.
- **Control systems:** PID Tuner, Control System Designer, Linear System Analyzer, Model Reducer, System Identification, MPC Designer.
- **Statistics and learning:** Distribution Fitter, Probability Distributions (Explore and Random samples modes; `disttool`, `randtool`), Classification Learner, Regression Learner, Optimize, Solve ODE, Spline Tool.
- **Neural networks:** Neural Net Fitting (`nftool`), Pattern Recognition (`nprtool`), Clustering (`nctool`) and Time Series (`ntstool`), with training progress and a Stop button. `nnstart` lists all four.
- **Fuzzy logic and econometrics:** Fuzzy Logic Designer (`fuzzyLogicDesigner`, Mamdani and Sugeno systems); Econometric Modeler (`econometricModeler`: series, diagnostics, model comparison, forecasts; ARIMA with GARCH, EGARCH or GJR variance).
- **Communications:** Bit Error Rate Analysis (`bertool`) and Wireless Waveform Generator (`wirelessWaveformGenerator`).
- **Images, video and volumes:** Image Viewer, Image Segmenter, Color Thresholder, Image Region Analyzer, Image Batch Processor, Registration Estimator, Camera Calibrator, Video Viewer (`implay`), DICOM Browser, Volume Viewer. Registration Estimator, Camera Calibrator, Video Viewer, DICOM Browser and Volume Viewer have a "Use sample data" button.
- **PDE Modeler** (`pdeModeler`): solves heat or voltage problems on a 2-D shape you draw, and shows the shape, its mesh and a colour map of the answer. Elliptic, parabolic (with a time slider), hyperbolic and eigenvalue problems; export to the workspace and a generated `createpde` script.
- **App Designer** (`appdesigner`): build a small window app from a component palette, with a property inspector, callback list, Code View, Save as `.m` and Run.

### Desktop
- **Window layout:** Settings > Window layout switches between Separate and Docked. In Separate layout the Editor and individual figures open in their own windows, apps share one Apps window, and new figures detach once the desktop is idle. In Docked layout they stay in the main window.
- **The Variable Editor is a spreadsheet:** select cells, copy and paste tab-separated text (it can grow the array), F2 to edit, undo, right-click on rows and columns.
- **New look:** pane titles and borders, text on toolstrip buttons, popped-out windows use the app theme. One "Unsaved work" dialog on quit covers figures, scripts and models.
- **Dialogs:** `uigetfile`, `uiputfile`, `uigetdir`, `listdlg`, `waitbar`, `msgbox`, `warndlg`, `errordlg`, `helpdlg` work in the desktop app. In `-batch`, the progress and message dialogs run without a window; blocking dialogs give a clear error.

### UI components and apps in code
- **UI components:** `uifigure`, `uigridlayout`, `uipanel`, `uitabgroup`, `uitab`, `uibutton`, `uilabel`, `uieditfield`, `uitextarea`, `uidropdown`, `uilistbox`, `uicheckbox`, `uibuttongroup`, `uiradiobutton`, `uislider`, `uispinner`, `uiswitch`, `uitable`, `uiaxes`, `uialert`, `uiconfirm`, `uiprogressdlg`. Function-handle callbacks receive `(src, event)`, cell callbacks can pass extra arguments, and text callbacks run in the base workspace. Plotting into `uiaxes` works. Without a window (`-batch`), objects and properties still work; `uiconfirm` returns the default choice, and `uialert` returns no value and runs its close callback immediately.
- **Classic figures:** `figure` with `uicontrol` (pushbutton, edit, text, slider, checkbox, popupmenu, listbox, radiobutton) and callbacks.
- **Apps as code:** classdef apps that derive from `matlab.apps.AppBase` run by name. App Designer shows the class code of readable `.mlapp` archives that contain it, read-only. Save editable designs as `.m` files.

### PDE toolbox (2-D)
- Geometry and mesh: `decsg`, `geometryFromEdges`, `pdegplot`, `generateMesh` (linear and quadratic triangles, `Hmax`, `Hmin`, `Hgrad`), `pdemesh`, `findNodes`, `findElements`.
- Solving: `createpde`, `specifyCoefficients`, `applyBoundaryCondition`, `setInitialConditions`, `solvepde` (stationary and time-dependent), `solvepdeeig`, `interpolateSolution`, `evaluateGradient`, `pdeplot`.
- Tests check known answers on the unit disk (Poisson, heat equation, Laplacian eigenvalues). On a square, measured convergence orders were 1.96-2.15 for linear triangles and 2.87-3.01 for quadratic triangles. Time-dependent solves are linear, with a limit of 4,096 states.

### Toolboxes behind the apps
- Shallow neural networks: `feedforwardnet`, `fitnet`, `patternnet`, `cascadeforwardnet`, `narxnet`, `narnet`, `timedelaynet`, `selforgmap`, and `train` with eight training functions for supervised networks.
- Fuzzy logic: `mamfis`, `sugfis`, `evalfis`, `readfis`, `writefis`, `plotmf`, `gensurf`, `defuzz` and the membership functions.
- Communications: `qammod`, `pskmod`, `pammod` and their demodulators, `awgn`, `berawgn`, `biterr`, `ofdmmod`, `ofdmdemod`, `rcosdesign`, `eyediagram`, `scatterplot`, `berfit`.
- Econometrics: `arima`, `garch`, `egarch`, `gjr` (`estimate`, `infer`, `forecast`, `simulate`), `autocorr`, `parcorr`, `adftest`, `kpsstest`, `lbqtest`, `archtest`.
- Model predictive control: `mpc`, `mpcmove`, `mpcsimopt`, `mpcstate`.
- Images and video: `dicominfo`, `dicomread`, `dicomwrite`, `dicomCollection`; `VideoReader` and `VideoWriter` (uncompressed and Motion JPEG AVI built in; reading other containers and AVI codecs needs `ffmpeg` and `ffprobe`; writing MPEG-4 (`.mp4`) or Motion JPEG 2000 (`.mj2`) needs `ffmpeg`); `imwarp`, `imregtform`, `imregister`, `imfuse`; camera calibration (`estimateCameraParameters`, `undistortImage`); volume functions (`isosurface`, `slice`, `volshow`).
- Other: `profile`, `visdiff`, `firls`, `kaiserord`, `iirnotch`, `iirpeak`, `phasedelay`; `fitlm`, `fitglm`, `fitcknn`, `fitctree`, `fitcsvm`, `boxplot`, `perfcurve`; `designfilt`; `pdepe` and `pdeval`.

### Sound
- `sound`, `soundsc`, `audioplayer` (`play`, `playblocking`, `pause`, `resume`, `stop`, `isplaying`) and `audiorecorder`. On Linux the sound library loads at run time, so a batch calculation runs without it. Playback without a sound device warns once and continues silently; recording needs an input device.

### Language and data
- Argument validation: `arguments` blocks in functions and methods (size, class, defaults, `mustBe*` validators, name-value). `Name=Value` call syntax works in function and method calls.
- Tables: `categorical` is a real array type; joins, groups, `groupsummary`; `timetable`, `retime`, `synchronize`, `calendarDuration`; `summary(T)`.
- Sparse: square systems use triangular substitution, Cholesky or LU for `\` and `/`; `ichol`, `ilu`; iterative solvers on sparse operands; `sprand*`, `spfun`, `amd`, `colamd`, `symamd`, `symrcm`; `gallery('poisson',n)`.
- Files: `xlswrite`, `webread`, `websave`, `weboptions` (uses the system `curl`), `h5read`, `h5create`, `h5write`, `ncread`; ASCII `load`/`save`; space-separated text import; a leading UTF-8 byte-order mark is skipped.
- Statistics: `fitlm`, `fitglm`, `stepwiselm` and `predict`; reduction flags (`'all'`, `vecdim`, `omitnan`); `round(x,n,'significant')`; set operations with `'rows'`.
- Optimisation and ODE options: `fzero`, `fminbnd`, `fminsearch` take `optimset` options, `Display`, `OutputFcn` and `PlotFcns`; the ODE solvers take `Events`, `NonNegative`, `OutputFcn`; `NonNegative` is not accepted by `ode23s` and `ode15i`, nor by `ode15s`, `ode23t` and `ode23tb` with a mass matrix.
- Control models: MIMO `tf`, `zpk` and `ss`, `pade`, the `damp` table, I/O delays.
- Classes: `classdef` typed properties and validators; metaclass and listener basics.

### Scripts, files and the command line
- Scripts: N-D array operations, N-D arrays and nested structs in MAT v5 and v7.3 files, and value and handle classes with inheritance. Strings, `datetime`, `duration` and objects cannot be saved to MAT files yet.
- Import options select column types for text and spreadsheet files.
- Toolboxes resolve `private/`, `+package` and `@Class` folders, with `addpath`, `savepath` and help for qualified methods. Windows-1252 `.m` files load.
- In the desktop, `edit notes.m` opens a file or starts a buffer. Commands accept multiple words, as in `format long g`. F5 runs the active script.
- The command line streams output, supports Ctrl+C and `--max-steps`, and exits with 1 for script errors and 2 for usage errors. The desktop and command line lift the default step cap. Serial `parfor` and `spmd` run on the client.

### Plots
- New: `line`, `quiver`, `quiver3`, `contour3`, `fsurf`, `fimplicit`, `animatedline`, `xline`, `yline`, `rectangle`, `gscatter`, `subtitle`, `print` (png, jpeg, tiff, pdf, svg, eps).
- Axis labels and titles draw `\frac` and `\sqrt` from the LaTeX subset on screen and in SVG, PNG and PDF export. Font sizes in exports follow the requested size.
- `histogram`, `contourf`, `plot3` and `surf` with date-aware axes. Small surface subplots no longer show stray lines, and `quiver` arrows stay visible.
- Default object settings through `groot` (`DefaultLineColor` and similar).

### Compatibility fixes from running real public scripts
A set of real public scripts is now run on Windows each round and the commonest failures are fixed. A pass means the script completed without error on Windows. Round 1 moved the pass rate from 207 of 517 to 232 of 515 scripts. Round 2 moved it to 273 of 515 (53.01 %): 41 newly passing, none lost. Of 229 comparable passes, 216 matched the Octave reference.
- Implicit expansion for elementwise operators and two-argument functions (`[1;2]+[1 2 3]`, `max`, `mod`, `atan2` and others).
- Nested functions in function files. A multi-output call without parentheses (`[x,y] = two;`). Indexed assignment that creates a struct array or a graphics array (`s(3) = struct('a',1)`).
- Parser forms such as `if (i>2) a = 1; end`, and command syntax with wildcards (`clear *_DEF`).
- Plot call forms: `subplot(211)`, `axis square`, extra legend labels warn instead of erroring.
- New functions: `pcolor`, `trisurf`, `sphere`, `surfl`, `voronoi`, `delaunayTriangulation`, `tetramesh`, `ishold`, `gpuDeviceCount` (always returns 0; MatRust computes on the CPU).
- Read-only file lookups (`load`, `fopen` in read mode, `readmatrix`, `exist`) search eligible relative names inside added folders when the file is not in the current folder. Absolute paths, names containing `..` and update or write modes never search.
- Size-vector forms (`eye(size(A))`), trailing commas in brackets, `optimset` and `odeset` with no arguments, `optimoptions` for the common solvers, `dbstack` with named function and script frames, `num2cell(A,dims)`, table variable names with spaces and punctuation (unique, 1-63 characters), `format shortEng`.
- `dfilt.df1` with `isfir`, `decomposition(A,'banded')` for dense real square double matrices, `mnrnd` with per-row trial counts, `vertexAttachments`, `bucky`; `patch` and `surface` call forms; colorbar `Title`.
- Earlier review rounds fixed about 50 bugs in tables, `timetable`, `datetime`, joins, DSP, statistics, indexing, integer maths, file I/O and the Variable Editor.

## Behaviour changes
- `disp(int32(3))` prints `   3` (three leading spaces) without type-wide padding, and `x = int32(3)` echoes an `int32` line. Integer arrays use narrower column widths.
- `max` and `min` with a char second argument now error. `sum` of `single` data accumulates in single by default, or in double with `'double'`. N-D integer `sum` and `prod` accumulate in double by default.
- `1:0:3` is a 1x0 empty. `mldivide` on integer matrices is refused, like the operator; a scalar left divisor works.
- `circshift` with a scalar shift and no dimension shifts the first non-singleton dimension; a vector supplies one shift per dimension.
- The default `ColorOrder` and `yyaxis` colours follow the plot palette, and change with an explicit figure-theme change for automatic colours.
- `tf`, `zpk` and `ss` display differently; numerator and denominator keep their scale, and returned coefficient vectors can have leading zero padding.
- `uigetfile`'s third output is the index of the first filter that matches the first selected filename, or 0 on no match or Cancel.
- In `-batch` and in the browser, blocking file dialogs give the error "dialogs need the desktop app".
- `subplot 211`, `figure 3`, `view 30 45`, `rng 5 twister` and `pause 0.5` accept number words in command form.

## Known gaps
- Not included in the PDE toolbox: 3-D geometry, STL import, structural, thermal and electromagnetic models, `adaptmesh`, `assempde`, `initmesh`.
- Not included in the UI components: `uihtml`, GUIDE `.fig` files, `matlab.uitest`, custom component authoring.
- Video: uncompressed and Motion JPEG AVI work natively; reading other containers or AVI codecs needs both `ffmpeg` and `ffprobe` (absolute tool paths also work). DICOM: some compressed transfer syntaxes error with their UID; individual DICOM reads and writes refuse files over 256 MiB, while the collection browser lists larger files from bounded headers.
- Not supported yet: `?Name` metaclass syntax, enumeration object arrays.
- A named desktop layout does not save Command-only mode; it restores as Editor. In Separate layout, a figure created during a run detaches once the desktop is idle.
- Updating an existing `.xlsx` workbook with `xlswrite` keeps other cell values but removes formulas, formatting, charts, merged cells and defined names throughout the workbook. `webread` and `websave` need the system `curl` and only do http and https. `pspectrum` is not available.
- Sound: on a real device, buffering can affect where playback resumes. Silent playback resumes at the paused sample.

## Install
- Homebrew: `brew install leoom-labs/tap/matrust`
- Scoop: `scoop bucket add matrust https://github.com/leoom-labs/scoop-bucket`, then `scoop install matrust`
- Or download an archive below.

- Each archive holds three programs: `matrust-desktop` (the desktop app), `matrust` (the command line) and `matrust-pdf-worker` (a helper; keep it in the same folder).

FUNCTION REFERENCE

estimate

Estimate unknown conditional variance parameters by maximum likelihood.

Try itView source help →

The source help has multiple entries for this name. They are preserved below in source order, including differing compatibility notes.

Source entry 1

Estimate NaN parameters of ARIMA, ARIMAX (regARIMA), and GARCH, EGARCH or GJR models by conditional maximum likelihood, including ARIMA with a conditional Variance model.

Syntax

[m,cov,logL,info] = estimate(m,y,Name=Value)

Example

m = arima(0,0,0); o = optimoptions(@fmincon,Algorithm="sqp",ConstraintTolerance=1e-7); f = estimate(m,[1;2;1;3;2;4],Options=o,Display="off"); f.Constant

Options accepts optimoptions(@fmincon,...) or a scalar struct. Algorithm="sqp" (default), "interior-point", "active-set", and the legacy "quasi-newton" name all run the same native dense SQP with OPG covariance. Supported controls include ConstraintTolerance (default 1e-7), OptimalityTolerance, StepTolerance, MaxIterations, MaxFunctionEvaluations and Display ("off", "none", "iter", "final"). Options.Display only controls optimizer iteration output; estimate's Display ("params" default, "full", "iter", "diagnostics", "off") controls the parameter report and diagnostics (Display="off" suppresses all output).

Constraints: positive innovation variance or GARCH/GJR constant; Student t DoF > 2; stationary nonseasonal/seasonal AR and invertible MA polynomials. GARCH/GJR coefficients are nonnegative and sum(GARCH)+sum(ARCH)+0.5*sum(Leverage) <= 1-ConstraintTolerance (the leverage term applies to GJR). GJR also requires ARCH+Leverage >= 0 at every lag. EGARCH requires a stable GARCH polynomial; its ARCH and leverage coefficients are unrestricted. Polynomial constraints use a scaled Schur test to bound companion-root moduli by 1-ConstraintTolerance (lag-operator roots lie outside the reciprocal radius). Known parameters stay fixed. User-given starting values (Constant0, AR0, SAR0, MA0, SMA0, Beta0, Variance0, DoF0, GARCH0, ARCH0, Leverage0, Offset0) override automatic starts and must be feasible (infeasible user starts error).

Differences from MATLAB: numeric series only; up to 128 active parameters and lag degrees up to 256 per ARIMA component (128 for volatility). The accepted algorithm names share one SQP implementation. Conditional likelihood uses the supplied presamples or the documented model-specific defaults; it is not an exact stationary Kalman likelihood. With X and no Y0, the first P responses are the presample, so the effective sample is P observations shorter.

Reference: https://www.mathworks.com/help/econ/arima.estimate.html and https://www.mathworks.com/help/econ/garch.estimate.html

Source entry 2

Estimate unknown conditional variance parameters by maximum likelihood.

Syntax

[m,cov,logL,info] = estimate(m,y,Name=Value)

GARCH degree P refers to variance lags; Q refers to innovation lags. NaN parameters are estimated, known values stay fixed. Gaussian and standardized Student t innovations are supported.

Example

estimate(garch(),[1;-1;2;-2],Display='off')

Differences from MATLAB: numeric arrays only; degree limited to 128 and estimated parameters to 128. MLE uses the shared native constrained SQP with OPG covariance (see estimate for algorithms and constraints). EGARCH forecasts exponentiate expected log variance and have the documented Jensen bias.

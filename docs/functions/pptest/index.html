pptest

Phillips-Perron unit-root test with Bartlett long-run variance correction.

Try itView source help →

Phillips-Perron unit-root test with Bartlett long-run variance correction.

Syntax

[h,pValue,stat,cValue,reg] = pptest(y,Model='AR',Lags=0,Test='t1',Alpha=.05)

Models AR, ARD and TS match adftest. Lags controls the Newey-West covariance bandwidth; the regression always contains only one lagged level. Test t1 is the corrected tau statistic; t2 is the corrected rho statistic. Missing observations are removed. Vector options expand as in adftest. reg additionally contains residual autoCov and the scalar long-run variance NWEst.

Example

[h,p,s,c,r]=pptest([1 3 2 5 4 7 6 2 3 1 5 2],Model='ARD',Lags=2)

Differences from MATLAB: numeric vectors only; tables/timetables unsupported. Published MacKinnon (1996) tau/rho response surfaces and linear quantile interpolation differ from MATLAB simulation tables. P-values clamp to [.001,.999] with warnings; fewer than 20 regression observations use the T=20 surface with a warning. Same limits as adftest; reg.names is a string vector.

Reference: https://www.mathworks.com/help/econ/pptest.html

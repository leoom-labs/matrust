wsst

Wavelet synchrosqueezed transform.

Try itView source help →

Wavelet synchrosqueezed transform.

Syntax

sst = wsst(x)

Syntax

[sst, f] = wsst(x, fs)

Syntax

[sst, f] = wsst(x, fs, wav)

Syntax

[sst, f] = wsst(..., Name, Value)

Sharpens the continuous wavelet transform of the real vector x along frequency: each coefficient moves to the bin of its instantaneous frequency, the phase transform imag(dW/dt ./ W)/(2*pi). sst has NV*(floor(log2(N)) - 1) rows and N columns; f (a row vector) holds the bin frequencies, log-spaced from fs/N to fs/2 and increasing. wav is 'amor' (default) or 'bump'. The transform keeps every coefficient above 1e-8 of the largest centred sample, weighted by log(2)/NV, so iwsst inverts it.

Options: 'VoicesPerOctave' (NV, even, 10 to 48, default 32), 'ExtendSignal' (reflect the signal at both ends, default false).

Example

t = (0:1023)/1024; [sst, f] = wsst(cos(2*pi*40*t), 1024); [~, k] = max(abs(sst(:, 512))); f(k)   % near 40

Differences from MATLAB: no plot without outputs; duration sampling periods are not supported; instantaneous frequencies outside the bins are assigned to the first or last bin instead of being dropped.

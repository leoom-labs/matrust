isfloat

True for floating-point arrays.

Try itView source help →

True for floating-point arrays.

Syntax

isfloat(A)

True for double and single arrays (real or complex); false for integer, logical and char arrays.

Example

tf = isfloat(single(1))

Differences from MATLAB: none known.

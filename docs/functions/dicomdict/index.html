dicomdict

Get or replace this Engine session's active DICOM dictionary.

Try itView source help →

Get or replace this Engine session's active DICOM dictionary.

Syntax

path = dicomdict('get'); dicomdict('set',filename); dicomdict('factory')

Factory lookup uses the compiled PS3.6 table. Get returns the file of the active dictionary: the canonical path given to set, or, while factory is active, a generated text copy of the compiled table (5299 rows) at <user cache folder>/matrust/dicom/<16 hexadecimal digits>/dicom-dict.txt on Linux (XDG_CACHE_HOME or ~/.cache), or <temporary folder>/matrust-dicom/<16 hexadecimal digits>/dicom-dict.txt on Windows and macOS. On Linux and other Unix systems except macOS, factory get errors if neither XDG_CACHE_HOME nor HOME supplies an absolute per-user cache folder. That copy is checked on every get and rewritten when missing or changed; it can be copied, edited and passed to set. Set validates and parses a text file once, then atomically replaces the current dictionary; failed sets preserve it. Relative paths use Current Folder. Factory restores the compiled table. dicominfo and dicomread use the active dictionary; their per-call 'Dictionary',filename option is parsed for that call only and leaves session state unchanged.

Text rows have four columns: (gggg,eeee) VR Keyword VM. Blank lines and # comments are allowed; hexadecimal tags may contain x wildcard nibbles, such as (60xx,0010). VRs use the PS3.5 codes; slash-separated alternatives (US/SS, OB/OW) preserve ambiguous factory VRs. VM accepts positive counts, ranges, n bounds and alternatives separated by ' or '. Keywords are 1..63 ASCII identifier characters starting with a letter. Duplicate tags and keywords are errors naming file and line; exact tags win over masks, and the most specific matching mask wins. A custom dictionary replaces factory naming and VRs, including private odd-group tags. Implicit private VR comes only from that dictionary; unknown primitive tags keep the existing skipped behavior.

Differences from MATLAB: factory get returns a generated copy in the user cache or temporary folder rather than a file shipped with the product; editing that copy changes nothing until it is passed to set, and the browser version has no file to return. Session state is per Engine; *_current actions are explicitly unsupported. Only text dictionaries are supported; MAT-format dictionaries error explicitly. Limits: 16 MiB input, 65536 entries, 1024 repeaters, 4096 bytes per line, and available engine memory. Parsing polls cancellation. Writer custom dictionaries and every dicomwrite Dictionary option are not supported yet; reset to factory before writing. No GUI or global path changes.

Example

dicomdict('factory')

Example

path = dicomdict('get')

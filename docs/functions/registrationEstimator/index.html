Open the desktop Registration Estimator to align a moving image with a fixed image and compare registration runs.

Syntax

registrationEstimator

Syntax

registrationEstimator(moving, fixed)

Example

try, registrationEstimator; catch err, disp(err.message); end

Requires the MatRust desktop; CLI calls report "registrationEstimator requires the desktop". moving and fixed are workspace variables holding H-by-W gray images (uint8, uint16, int16, single or double) or H-by-W-by-3 RGB images (uint8, uint16, single or double); RGB images are registered on their rgb2gray version and the registered image keeps its colour. Use sample data loads a synthetic pair (two Gaussian blobs at 0-255, moving = fixed under rigidtform2d(8,[6 -4])) and selects Rigid; Generate script then rebuilds that pair itself. Images can also be read from files, and optional imref2d variables place either image in world coordinates. Each Register press runs imregtform off the UI thread (cancellable) with the chosen technique (monomodal: MeanSquares and RegularStepGradientDescent; multimodal: MattesMutualInformation and OnePlusOneEvolutionary), transformation type (translation, rigid, similarity or affine), pyramid levels, maximum iterations, maximum step length or initial radius and optional initial transformation, then warps the moving image into the fixed frame with imwarp and OutputView. Every run is listed with its time and the normalized correlation of the registered and fixed images over the fixed frame; runs are kept until the images change. The view overlays fixed and moving or registered images with imfuse (falsecolor, blend, checkerboard or diff). Export writes the transformation, the registered image, its imref2d and the quality value of the selected run (existing names are replaced transactionally); Generate script saves the code that reproduces that run.

Differences from MATLAB: 2-D images only; no feature-based techniques, nonrigid (displacement field) registration, masks or session files.

Reference: https://www.mathworks.com/help/images/ref/registrationestimator-app.html

DEMO

One minute, start to finish.

Write a script, run it, use the Command Window, then the same code in the browser.

WHAT WORKS

The core language, natively.

01

Language

Scripts, functions, control flow, structs, cells, handles, try/catch and switch.

02

Numeric types

Double, single, int8–uint64, logical, char and complex.

03

750+ functions

Built-in help pages document syntax, examples and compatibility notes.

04

Plotting

Explore results with plots, then export to image and vector formats.

05

MAT and CSV files

Save and load a workspace, or exchange data with other tools.

06

Desktop tools

A Filter Designer and a discrete-time Block Simulation tool.

Not yet: toolboxes, Simulink, classdef, N-D and sparse arrays. See the full list.

TRY IT

Runs in your browser, too.

Write a few lines, run a calculation and see the result.

Open in the browser console

The browser version runs on your device. Your code is not sent anywhere.

example.mScript
A = [3 1; 1 2];
b = [9; 8];
x = A \ b;
disp(x)
t = linspace(0, 2*pi, 100);
plot(t, sin(t))
Command Window
     2
     3
